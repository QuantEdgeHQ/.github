# Support

This document explains where to get help with repositories and projects in this organization.

## Before Asking for Help

- Check the relevant repository's `README.md` for setup and usage instructions
- Search existing [issues](../../issues) to see if your question has already been answered
- Review `CONTRIBUTING.md` if your question is about contributing code

## Getting Help

- **Bug reports:** Open an issue in the relevant repository, using the bug report template if available
- **Feature requests:** Open an issue using the feature request template
- **Security issues:** Do **not** open a public issue — see `SECURITY.md` for responsible disclosure instructions
- **General questions:** Open a [Discussion](../../discussions) if enabled on the repository, or reach out via the contact details below

## Contact

- **Email:** [support@yourdomain.com]
- **General inquiries:** [contact@yourdomain.com]

## Response Times

We aim to respond to issues and support requests within a reasonable timeframe, though response times may vary depending on complexity and current workload. Security reports are prioritized — see `SECURITY.md` for details.
