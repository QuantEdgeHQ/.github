# .github

Community health files and shared configuration for the QuantEdge GitHub organization.

## Contents

| File | Purpose |
|---|---|
| `profile/README.md` | Org profile page (shown on the org homepage) |
| `COPYRIGHT.md` | Copyright notice |
| `DISCLAIMER.md` | Financial disclaimer |
| `SECURITY.md` | Vulnerability reporting policy |
| `SUPPORT.md` | How to get help |
| `CONTRIBUTING.md` | Contribution guidelines |
| `CODE_OF_CONDUCT.md` | Expected behavior for contributors |
| `ISSUE_TEMPLATE/` | Default issue templates, applied org-wide |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template, applied org-wide |

These files act as defaults across all repositories in this organization that don't define their own.
